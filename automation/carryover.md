# Carryover queue

Stories the editor has explicitly asked to cover on the next daily run, even though they fall
outside the normal 48-hour window. The run covers these FIRST, still duplicate-checks them
against LFJ, and counts them toward the day's cap. After a successful run the file is
archived to `automation/logs/carryover-<date>.done.md` and emptied, so nothing repeats.

To queue something: add a `- ` bullet below with the headline, the source URL, and a note.
To cancel: delete the bullet.
